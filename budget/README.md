# Household Budget

Budget de foyer partagé pour deux personnes : budget mensuel par catégorie, dépenses « à la Tricount » (qui a payé quoi, répartition
selon les revenus), solde entre vous deux, épargne et récap mensuel par IA. S'intègre à Home Assistant via Ingress
(entrée **Budget** dans la barre latérale).

Voir l'onglet **Documentation** pour le détail.
